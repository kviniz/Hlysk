# Hlysk.

**Меньше шума. Больше контроля.**
Строгая модерация, интерактивные заявки и глобальная синхронизация без перегруженных интерфейсов.

---

### ✦ Возможности

1. **Выговоры и лимиты:** Настраиваемые наказания с автоматическим снятием ролей и логированием действий.
2. **Анкеты и тикеты:** Создание приватных каналов-собеседований одним нажатием через модальные окна.
3. **Логирование:** Автоматическая генерация `.txt` транскриптов диалогов после закрытия собеседований.
4. **Wsync (Глобальная сеть):** Автоматическая синхронизация выговоров и наказаний между всеми вашими серверами.

---

### ✦ Справочник команд

Все команды поддерживают как Slash (`/`), так и Prefix (`h.`) форматы.

#### 🛡 Выговоры (Доступ: Кураторы)

| Команда | Параметры | Описание |
| :--- | :--- | :--- |
| `/warnadd` | `@пользователь`, `причина`, `[кол-во=1]` | Выдать выговор. При достижении лимита применяются наказания. |
| `/warnremove` | `@пользователь`, `[кол-во=1]` | Уменьшить счетчик выговоров пользователя. |
| `/warnclear` | `@пользователь` | Полностью обнулить историю выговоров пользователя. |

#### ⚙️ Настройки (Доступ: Администратор)

| Команда | Описание |
| :--- | :--- |
| `/settings` | Интерактивное меню конфигурации (Начальная роль, Выговоры, Заявки). |

#### 🔗 Система Wsync (Доступ: Администратор)

| Команда | Параметр | Описание |
| :--- | :--- | :--- |
| `/wsync` | `[пусто]` | Сгенерировать ключ текущего сервера для передачи. |
| `/wsync` | `ключ` | Ввести ключ для объединения баз данных с другим сервером. |
| `/wsync` | `list` | Посмотреть список серверов в текущей сети синхронизации. |
| `/wsync` | `disconnect [ID]` | Отключить сервер от глобальной сети. |

#### ℹ️ Информация (Доступ: Все пользователи)

| Команда | Описание |
| :--- | :--- |
| `/warnlist` | Интерактивный список истории выговоров участника. |
| `/help` | Вызов встроенной справки по командам. |
