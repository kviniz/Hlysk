Справочник

Полная документация по командам и их параметрам.

Выдает пользователю выговор. Бот проверяет лимит, отправляет отчет в логи и уведомляет участника. При достижении лимита применяются настроенные наказания.

Параметры
  • пользователь (обязательно)
  • причина (обязательно)
  • кол-во (опционально, по умолч. 1)

Доступ Кураторы

Открывает главное интерактивное меню для конфигурации бота на вашем сервере. Позволяет настраивать модули без ввода сложных текстовых команд.

Доступные модули в меню:
  • Начальная роль Выбор роли, которая будет автоматически выдаваться при входе.
  • Система выговоров Настройка каналов отчетов, логов, лимитов, а также ролей кураторов и ролей для снятия.
  • Заявки Создание анкет с вопросами, настройка каналов транскриптов и категорий для тикетов-собеседований.
Доступ Администратор

Управление глобальной сетью серверов. Позволяет сгенерировать ключ или ввести чужой ключ для объединения баз данных выговоров. Выданный выговор на одном сервере будет применен на всех серверах сети.

Параметры
  • [пусто] Сгенерировать ключ текущего сервера для передачи.
  • ключ Ввести сгенерированный ключ для объединения с другим сервером.
  • list Посмотреть список серверов в текущей сети синхронизации.
  • disconnect [ID] Отключить сервер из сети.
